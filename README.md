
#  Projeto Tabuada

Projeto desenvolvido para praticar conceitos de JavaScript, HTML e CSS.

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

##  Funcionalidades

- Inserção de um número para multiplicação.
- Definição da quantidade de multiplicações.
- Geração dinâmica dos resultados.
- Exibição dos resultados na tela.

##  Objetivo

Praticar lógica de programação, manipulação do DOM, eventos e estruturas de repetição em JavaScript, junto com o professor Matheus Battisti.
